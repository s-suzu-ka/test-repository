# 課題の言語化

## 表面的な課題

- 電車の遅延情報を、駅についてから初めて知ってしまう

## 深掘りで明らかになった根本課題

- いつもの路線は「今日も正常に動いているはず」という前提で行動してしまい、そもそも遅延の可能性を考えない
- 朝は時間的余裕がなく、能動的に確認するアクションを取れない
- 遅延を知るだけでは不十分で、代替路線までわからないと実際に対処できない

## 課題が発生している状況・背景

- **誰が困っているか**: 本人（毎朝通勤・通学で同じ路線を使っている）
- **どんな場面で発生するか**: 朝の出発前〜駅到着時
- **現在の対処方法**: 駅に着いてから遅延に気づき、その場で対処を考える
- **解決できない場合の影響**: 遅延に気づくのが遅れ、遅刻や予定変更が後手になる

## なぜなぜ分析のサマリー

1. **なぜ1**: なぜ駅に着いてから知るのか → いつもの路線は出発前に確認する習慣がない
2. **なぜ2**: なぜ確認する習慣がないのか → そもそも遅延という発想にならない＋毎回確認が面倒
3. **なぜ3**: なぜ毎回確認が面倒なのか → 朝は時間的余裕がない
4. **なぜ4**: 遅延がわかれば解決するか → 代替路線も提示されないと実際には動けない
