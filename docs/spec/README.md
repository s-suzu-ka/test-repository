# 電車遅延通知Bot

朝の通勤・通学時に電車の遅延を自動検知し、代替路線とともにLINEへ通知する個人用Botです。

## 採用アプローチ

**LINE通知Bot（方向性B）** を採用。個人利用かつ開発コストを抑えたいため、既存のLINEアプリへ通知する構成を選択。

## 技術スタック（予定）

| レイヤー     | 技術                                             |
| ------------ | ------------------------------------------------ |
| スクリプト   | TypeScript                                       |
| 遅延情報取得 | Yahoo!路線情報 / 鉄道遅延なう API                |
| 代替路線     | Yahoo!乗換案内API / 国交省公共交通オープンデータ |
| 通知         | LINE Messaging API                               |
| 実行環境     | GitHub Actions                                   |

## 開発フェーズ

- **Phase 1（MVP）**: 1路線の遅延検知 → LINE通知（代替路線なし）
- **Phase 2**: 代替路線提示・通知時間帯の設定
- **Phase 3**: 複数路線対応・休日スキップ・遅延解消通知
