# 電車遅延通知Bot — 要件定義

朝の通勤・通学時に電車の遅延を自動検知し、代替路線とともにLINEへ通知する個人用Botの要件定義ドキュメントです。

## 背景

駅に着いてから遅延を知り、対処が後手になるという課題を解決するため、遅延発生時のみプッシュ通知する仕組みを検討しました。

## ドキュメント構成

```text
要件定義/
├── 課題の言語化.md   # 表面課題・根本課題・なぜなぜ分析
├── 打ち手の方向性.md # 解決アプローチの比較と推奨案
└── 要件定義書.md     # 機能要件・非機能要件・技術スタック・開発フェーズ
```

| ドキュメント | 内容 |
| --- | --- |
| [課題の言語化](要件定義/課題の言語化.md) | 課題の深掘りとなぜなぜ分析 |
| [打ち手の方向性](要件定義/打ち手の方向性.md) | アプリ・LINE Bot・メール通知の比較 |
| [要件定義書](要件定義/要件定義書.md) | 機能要件・技術スタック・開発フェーズ案 |

## 採用アプローチ

**LINE通知Bot（方向性B）** を採用。個人利用かつ開発コストを抑えたいため、既存のLINEアプリへ通知する構成を選択。

## 技術スタック（予定）

| レイヤー | 技術 |
| --- | --- |
| スクリプト | Python |
| 遅延情報取得 | Yahoo!路線情報 / 鉄道遅延なう API |
| 代替路線 | Yahoo!乗換案内API / 国交省公共交通オープンデータ |
| 通知 | LINE Messaging API |
| 実行環境 | GitHub Actions または Render（無料枠） |

## 開発フェーズ

- **Phase 1（MVP）**: 1路線の遅延検知 → LINE通知（代替路線なし）
- **Phase 2**: 代替路線提示・通知時間帯の設定
- **Phase 3**: 複数路線対応・休日スキップ・遅延解消通知
